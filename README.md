# 미디어닷 (MediaDot)

멀티 플랫폼 **콘텐츠 자동발행 & 광고수익 관리** 시스템 — 주제 선정부터 원고 작성, 플랫폼별 리라이팅, 배포, 수익 집계까지 하나의 다크 테마 대시보드에서 관리합니다.

## 실행

```bash
npm install                    # 의존성 + 크로미움 자동 설치(postinstall)
# 크로미움 자동 설치가 실패했다면 한 번만 직접 실행:
npm run setup-browser          # = playwright install chromium
npm start                      # http://localhost:3400
```

- **Node.js 22.5 이상** 필요 (내장 `node:sqlite` 사용 — 별도 DB 설치 불필요)
- **네이버 블로그·티스토리 자동 발행**에는 크로미움 브라우저가 필요합니다. `npm install`이 자동으로 받지만(postinstall), 막힌 환경이면 `npm run setup-browser`를 실행하세요. 미설치 시 자동 발행이 수동 발행(복사·붙여넣기)으로 안전하게 전환됩니다.
- 첫 실행 시 데모 데이터(카테고리·계정·매칭·주제·수익)가 자동 시드됩니다. 모두 수정/삭제 가능.
- DB는 `data/mediadot.db`에 저장됩니다. 초기화하려면 `data/` 폴더를 삭제하세요.

## 핵심 개념

```
주제 선정 ─► 마스터 원고 작성(AI) ─► 정책 검사 ─► 플랫폼별 리라이팅(+삽화·카드뉴스·광고 문구) ─► 배포
                                                            │
                              컨펌 모드: 발행 큐에서 승인 후 발행
                              자동 모드: 계정별 시간 분산 예약 → 스케줄러가 자동 발행
                              (정책 위험 '높음' 검출 시 자동 모드라도 승인 대기로 강제 전환)
```

**원클릭 발행** — 대시보드 상단에서 카테고리 선택 후 "지금 발행" 클릭 한 번이면 전체 파이프라인이 실행되고, 진행 상황(주제 선정 → 원고 작성 → 정책 검사 → 리라이팅 n/m → 발행)이 실시간 스테퍼로 표시됩니다.
**프리플라이트** — 실행 전 AI 엔진·계정 인증·공개 URL·일일 상한·주제 풀을 자동 점검해 체크리스트로 보여주고, 문제 항목에는 "해결하러 가기" 링크가 붙습니다.

| 화면 | 역할 |
|---|---|
| **대시보드** | 수익 추이·플랫폼별 수익·발행 현황·활동 로그 종합 |
| **콘텐츠 스튜디오** | 주제 풀 관리, AI 주제 발굴, ⚡자동발행 실행, 콘텐츠 상세(파이프라인 진행/변형별 상태) |
| **발행 큐** | 승인 대기(최종 컨펌) · 예약 발행 · 수동 발행(복사·붙여넣기) · 실패 재시도 · 카드뉴스/삽화 미리보기 |
| **계정 · 매칭** | 미디어 계정(발행처) + 광고 계정(수익원) 등록, 상호 매칭, 궁합 가이드 |
| **카테고리** | 이슈/생활정보 등 주제 분류 — 계정·주제·자동발행이 카테고리 단위로 묶임 |
| **지침** | 플랫폼별 글쓰기·리라이팅 지침 표출·수정 — 수정하면 다음 발행부터 프롬프트에 적용 |
| **수익** | 광고 플랫폼별 수익 기록·집계·추이 |
| **설정** | 발행 모드, 자동발행 시각, 발행 안전장치, AI 텍스트 엔진(Claude/Copilot), 이미지 엔진(Gemini)·카드뉴스 |

## 카테고리 기반 운영

"이슈 → 이슈 블로그·인스타 계정", "생활정보 → 생활정보 블로그 계정"처럼 **카테고리에 계정을 연결**하면, 해당 카테고리의 자동발행 시 그 계정들에만 리라이팅·배포됩니다.

## 발행 모드

- **컨펌 후 발행** (기본): 리라이팅까지 자동 → 발행 큐에서 사용자가 검토·승인해야 배포
- **완전 자동**: 리라이팅 완료 즉시 계정별 시간 분산 예약 → 스케줄러가 자동 배포
- **정기 자동발행**: 설정에서 켜면 지정 시각(예: 09:30, 19:30)마다 "정기 자동발행 ON" 카테고리의 파이프라인이 통째로 자동 실행

## 수익 보호 전략 (내장)

자동발행이 검열·저품질 판정으로 수익을 못 내는 상황을 막기 위한 장치들:

1. **플랫폼별 카피라이터 리라이팅** — 블로그(공감 도입→해결→결론 스토리텔링, 키워드 5~7회 자연 배치), SNS(첫 줄 훅, 글자수 하드리밋 자동 검증 — X 한글 140자 등), 숏폼(구어체 나레이션, 중반 CTA+고정 댓글)까지 플랫폼 알고리즘에 맞춘 전략이 프롬프트에 내재화. 지침 탭에서 수정 가능
2. **광고 맥락 연동** — 계정에 매칭된 수익원(쿠팡 파트너스·애드센스 등)을 리라이팅에 주입 → 블로그 결론부 "함께 보면 좋은 정보", SNS 바이오 링크 유도, 숏폼 고정 댓글 CTA가 자동 생성. 쿠팡 연결 시 대가성 문구 자동 포함
3. **광고 정책 검사** — 위반 표현 검출 + **대체 표현 제안**("완치" → "증상 완화에 도움") + 위반 문맥 표시. 위험 '높음'이면 완전 자동 모드라도 승인 대기로 강제 전환
4. **발행 분산** — 계정 간 발행 간격(기본 25분+지터) + 계정별 일일 상한(기본 3건)으로 스팸 신호 차단
5. **본문 삽화 자동 삽입** — Gemini가 [이미지: …] 마커 위치에 삽화를 생성해 발행 시 삽입 (텍스트 벽 방지)
6. **주제 중복 방지** — 발행 이력을 스튜디오에서 확인, AI 주제 발굴 시 기발행 주제 자동 제외 + 유사도 검사로 재발행 차단
7. **수동 발행 폴백** — 자동 발행이 막히면(캡차·2단계 인증 등) 완성 원고 복사 → 붙여넣기 → "발행 완료 표시"로 이어서 관리

## 지원 플랫폼

**미디어(발행):** 블로그스팟(Blogger)ᴬ · 네이버 블로그ᴮ · 티스토리ᴮ · 워드프레스ᴬ · 인스타그램ᴬ · 페이스북ᴬ · 스레드ᴬ · X(트위터)ᴬ · 틱톡ᴹ · 유튜브 쇼츠ᴹ
(ᴬ=API 자동발행 · ᴮ=브라우저 자동발행: 공식 API가 없어 Playwright가 로그인→작성→이미지 업로드→발행까지 대행, 실패 시 반자동 폴백 · ᴹ=반자동: 완성 원고 복사·붙여넣기)

### 네이버 블로그 · 티스토리 완전 자동화 (브라우저 발행)

계정 · 매칭에서 로그인 정보(네이버: 아이디/비밀번호, 티스토리: 카카오 계정+블로그 이름)를 등록하면 발행 시 Chromium이 자동으로:
로그인(세션은 `data/sessions/`에 저장·재사용) → 에디터 진입 → 제목·본문 입력 → **[이미지: …] 마커 위치에 생성 삽화 업로드** → 태그 입력 → 공개 발행 → 게시 URL 회수.
캡차·2단계 인증 등으로 자동화가 막히면 원인 안내와 함께 수동 발행(복사·붙여넣기)으로 자동 전환됩니다.

### 인스타그램 카드뉴스 자동 제작·업로드

인스타그램 변형은 "=== 카드 N ===" 구분으로 리라이팅되고, 파이프라인이 이를 **1080×1080 다크 테마 카드 이미지**로 자동 렌더링합니다(표지+본문+CTA, 카테고리 색상 반영, 브랜드 핸들 표시).
- Meta 자격증명 + 서버 공개 URL(public_base_url) 설정 시 **Graph API 캐러셀로 자동 업로드**
- 없으면 발행 큐에서 카드 이미지를 내려받아 수동 업로드

**광고(수익):** 구글 애드센스 · 네이버 애드포스트 · 카카오 애드핏 · 쿠팡 파트너스 · 타불라 · 데이블 · 텐핑(CPA) · 틱톡 크리에이터 리워드 · 유튜브 파트너

## 수익 자동 동기화

리포트 API를 제공하는 광고 플랫폼은 **계정 · 매칭**에서 자격증명을 등록하면 매일 지정 시각(기본 06:10)에 일별 수익이 자동 반영됩니다. 수익 화면의 "전체 동기화" 버튼으로 즉시 실행도 가능합니다.

| 플랫폼 | 자동 연동 | 필요 자격증명 |
|---|---|---|
| 구글 애드센스 | ✅ AdSense Management API v2 | 게시자 ID + Google OAuth(client_id/secret/refresh_token, `adsense.readonly` 스코프) |
| 쿠팡 파트너스 | ✅ Open API 커미션 리포트 | Access Key + Secret Key (파트너스 → 추가기능 → Open API) |
| 타불라 | ✅ Backstage API | Client ID/Secret + Account ID (담당자 발급, USD → 설정 환율로 원화 환산) |
| 유튜브 파트너 | ✅ YouTube Analytics API | Google OAuth (`yt-analytics-monetary.readonly` 스코프) |
| 애드포스트 · 애드핏 · 틱톡 리워드 · 텐핑 | ❌ 공식 API 없음 | 정산 화면 값을 수익 화면에서 수동 기록 |

- 동기화 행은 `자동` 출처로 저장되며 같은 날짜의 자동 기록만 갱신 — **수동 입력 기록은 보존**됩니다.
- 확정치가 늦게 반영되는 플랫폼을 위해 매번 최근 N일(기본 7일)을 다시 덮어씁니다.

## AI 엔진

**텍스트 (셋 중 하나만 있으면 동작, 설정에서 우선순위 선택 · 준비 안 된 엔진은 자동 폴백):**
- **Claude API** — Anthropic API 키 등록 (`claude-opus-4-8` 기본). 환경변수 `ANTHROPIC_API_KEY`로도 설정 가능
- **GitHub Copilot** — 설정에서 "GitHub로 로그인"(디바이스 코드 입력)하면 개인 Copilot 구독으로 원고 작성·리라이팅 수행. *개인 구독 계정에서만 사용하세요*
- **Google Gemini** — Gemini API 키(AI Studio) 또는 **Google 계정 로그인**(아래)으로 `gemini-2.5-flash`/`pro` 사용
- 모두 없으면 **데모 모드** — 자리표시 원고로 전체 파이프라인 흐름 확인 가능

**이미지 (Gemini):**
- **Gemini API 키**(Google AI Studio 발급) 또는 **Google 계정 로그인**으로 리라이팅 원고의 `[이미지: …]` 마커 위치에 삽화를 자동 생성 (`gemini-2.5-flash-image` 기본)
- 생성 파일은 `data/uploads/`에 저장 — 네이버·티스토리는 발행 시 파일 직접 업로드, 블로그스팟·워드프레스는 public_base_url 기준 `<img>` 태그 삽입
- 설정 화면의 "이미지 생성 테스트" 버튼으로 동작을 즉시 확인

### Google 계정 연결 (텍스트·이미지 공용 OAuth)

API 키 대신 Google 계정 로그인으로 Gemini 텍스트·이미지를 함께 사용할 수 있습니다.
1. Google Cloud Console → API 및 서비스 → 사용자 인증 정보 → **OAuth 클라이언트(유형: TV 및 입력 제한 기기)** 생성
2. 사용 프로젝트에서 **Generative Language API** 사용 설정
3. 설정 화면에 Client ID/Secret 입력 후 "Google로 로그인" → 표시된 코드를 Google 인증 페이지에 입력
- refresh token은 서버에만 저장되며 화면·파일로 내보내지 않습니다. Gemini API 키가 있으면 키를 우선 사용하고, 없으면 이 연결로 대체됩니다.

## 계정·매칭 백업 (내보내기 / 가져오기)

계정 · 매칭 화면 상단의 **내보내기 / 가져오기**로 등록 내역을 JSON 파일로 저장·복원합니다.
- **내보내기** — 미디어 계정·광고 계정·매칭·카테고리 연결을 파일로 저장. "자격증명 포함" 옵션으로 비밀번호·API 키·토큰까지 백업(평문이므로 안전 보관) 또는 계정 목록만 저장 선택
- **가져오기** — 다른 기기/새 설치에서 파일로 복원. 같은 (플랫폼+이름) 계정은 중복 생성하지 않고 갱신(upsert), 카테고리는 이름으로 연결(없으면 생성), 매칭은 새 ID로 재매핑. "자격증명 덮어쓰기" 여부 선택 가능

## 시뮬레이션 → 실전 전환

기본값은 **시뮬레이션 발행**(외부 API 호출 없음)입니다. 실제 배포로 전환하려면:

1. 설정에서 Anthropic API 키 등록 (실제 원고 생성)
2. 계정 · 매칭에서 각 플랫폼의 자격증명 등록 (Blogger OAuth 토큰, Meta Page 토큰 등)
3. 설정에서 "시뮬레이션 발행 모드" 끄기
4. 초기에는 **컨펌 모드**로 품질을 확인한 뒤 완전 자동으로 전환 권장

## 구조

```
server/
  index.js       Express API
  db.js          node:sqlite 스키마·설정
  catalog.js     플랫폼 카탈로그 + 리라이팅 전략 프로파일(기본값)
  guidelines.js  지침 오버라이드 (기본 프로파일 위에 사용자 수정 적용)
  llm.js         텍스트 엔진 (Claude API / GitHub Copilot / Google Gemini, 구조화 출력)
  copilot.js     GitHub Copilot 디바이스 플로우 로그인 + chat completions
  google-oauth.js Google 계정 디바이스 플로우 로그인 (텍스트·이미지 공용)
  gemini.js      Gemini 공용 호출 (API 키 또는 Google OAuth)
  images.js      Gemini 이미지 생성 + 본문 [이미지:…] 마커 처리
  accounts-io.js 계정·매칭 내보내기/가져오기 (upsert 복원)
  cardnews.js    인스타 카드뉴스 렌더러 (Playwright HTML→1080×1080 PNG)
  browser.js     공용 Chromium 실행·로그인 세션 관리
```
